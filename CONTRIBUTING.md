# Come contribuire

Grazie per l’interesse a IMAP Organizer.

## Segnalazioni

- Apri una **issue** su GitHub descrivendo il problema o la proposta
- Indica versione / ambiente (OS, Node, MongoDB) e passi per riprodurre
- Non inserire password, token o dati personali nelle issue

## Pull request

1. Fai un fork del repository e crea un branch dedicato
2. Mantieni le modifiche mirate (una feature / un fix per PR)
3. Assicurati che `npm run build` e i test rilevanti passino
4. Non committare file segreti (`.env`, `apps/pi/auth.json`, `apps/api/spid/sp-key.pem`)
5. Descrivi nella PR il *perché* del cambiamento

## Ambiente di sviluppo

Vedi il [README](./README.md) per installazione, variabili d’ambiente e avvio locale.
